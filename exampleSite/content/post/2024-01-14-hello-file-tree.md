Every post is a file. That is the whole idea: the tree on the left is the site, and a page
is opened rather than navigated to.

## A short list

- posts are named as the file they are
- the front matter is shown as what it is
- code is set in the same fourteen inks as the app

```go
package main

import "fmt"

func main() {
	// Comments are prose, so they are set in the reading face.
	fmt.Println("hello, file tree")
}
```

> A quotation sits on a band with a rule down its left edge, which is what the app does.
